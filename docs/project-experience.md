# ForgeMind AI｜研发协作 Agent 平台项目实践说明

## 项目定位

面向个人项目和小型开发团队的仓库分析与知识检索工作台，将 GitHub 研发记录、本地代码与项目文档集中到一个交互入口，辅助查阅项目背景、排查问题和整理协作信息。

## 可用于简历的描述

**项目名称：** ForgeMind AI｜研发协作 Agent 平台
**参与角色：** 项目部署与集成实践  
**起止时间：** 根据实际参与时间填写。

**项目简介：** 基于现有 AI Agent 课程项目进行部署与定制，整合 GitHub 仓库、本地代码和项目文档，为 Issue 查阅、PR 分析、CI 排查及知识问答提供统一入口。采用 Next.js、FastAPI、PostgreSQL 与 Milvus，接入 DeepSeek，并使用本地 Qwen 嵌入模型进行文档向量化。

**个人工作：**

- 搭建 Windows 本地运行环境，部署前后端、关系数据库与向量检索服务，处理 Python 依赖冲突和基础服务镜像失效问题。
- 完成 DeepSeek 与 GitHub 接入，建立代码仓库并验证首次数据同步；针对本机端口占用，将后端调整为 8001。
- 配置本地 Qwen 嵌入模型，验证 1024 维向量生成；将知识库重排配置为现有本地启发式实现，减少对额外云服务凭据的依赖。
- 调整启动流程中的 UTF-8 和代理配置，适配中文目录与本机网络环境，整理一键启动入口及运行说明。
- 定制项目名称、页面标题和展示文案；完成相关模块测试与服务健康检查。

## 表述边界

Agent 编排、工具调用、混合检索、记忆机制与评测框架主要来自原课程源码。没有实际修改或充分理解的模块，不应写为个人独立设计。不要使用未测量的准确率、性能提升或用户规模；通过单项模型测试也不等于知识库全流程验收。项目来自 DevFlow AI 课程源码，改名用于个人展示，不代表从零原创开发。
